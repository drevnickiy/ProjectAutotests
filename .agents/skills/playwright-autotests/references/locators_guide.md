# Playwright Locators Guide & Best Practices

Locators are the central piece of Playwright's auto-waiting and retry-ability. Locators represent a way to find element(s) on the page at any given moment.

---

## 1. User-Facing Built-in Locators

### `page.getByRole(role, options)`
Locates by accessibility role and accessible name. This is the **primary and most recommended** locator.

```typescript
// Button with exact name
page.getByRole('button', { name: 'Зберегти', exact: true });

// Case-insensitive regex match for headings
page.getByRole('heading', { name: /список замовлень/i });

// Tab element
page.getByRole('tab', { name: 'Етапи та завдання' });

// Checkbox / Radio
page.getByRole('checkbox', { name: 'Обов\'язкове' });

// Dialog / Modal
page.getByRole('dialog', { name: 'Створення продукту' });
```

### `page.getByLabel(text, options)`
Locates inputs, selects, textareas associated with a `<label>` or having `aria-label`.

```typescript
page.getByLabel('Номер замовлення');
page.getByLabel(/термін придатності/i);
```

### `page.getByPlaceholder(text, options)`
Locates input elements by their placeholder attribute.

```typescript
page.getByPlaceholder('Введіть назву продукту...');
```

### `page.getByText(text, options)`
Locates elements by their visible text content.

```typescript
// Strict exact text
page.getByText('Успішно збережено', { exact: true });

// Substring match
page.getByText('Hydrasence 400 мл');
```

## 2. Filtering and Chaining Locators

### Filtering by Child or Text
Use `.filter()` to narrow down repeating elements (such as rows in a table or cards in a grid).

```typescript
// Find the row that contains specific customer name
const userRow = page.locator('tr, [role="row"]')
  .filter({ hasText: 'ТОВ "Фарма Груп"' });

// Click the Edit button inside THAT specific row
await userRow.getByRole('button', { name: 'Редагувати' }).click();

// Filter by child element
const activeCard = page.locator('.card')
  .filter({ has: page.getByRole('button', { name: 'Активний' }) });
```

### Chaining Locators
Chain locators to scope searches within a specific container/modal.

```typescript
const modal = page.locator('crt-modal, [role="dialog"]');
const nameInput = modal.getByRole('textbox', { name: 'Назва' });
const saveButton = modal.getByRole('button', { name: 'Зберегти' });

await nameInput.fill('Нова назва');
await saveButton.click();
```

## 3. Lists and Multiple Elements

### Iterating over locators
```typescript
const items = page.locator('.product-item');
const count = await items.count();

for (let i = 0; i < count; ++i) {
  console.log(await items.nth(i).innerText());
}
```

### `all()` for modern async iteration
```typescript
for (const row of await page.locator('table tr').all()) {
  const text = await row.innerText();
  if (text.includes('Деактивовано')) {
    await row.getByRole('button', { name: 'Видалити' }).click();
  }
}
```

## 4. Avoiding Flakiness in Locators

1. **Avoid Strict Mode Violations**: If a locator resolves to multiple elements, Playwright throws a `strict mode violation`. Either make the locator more specific or use `.first()`, `.last()`, or `.nth(index)` explicitly.
2. **Handle Dynamic Attributes**: Never use autogenerated IDs like `#id_1787291823`. Use accessible roles or structural parent filters instead.
3. **No Hidden Overlays**: Ensure dialogs/overlays have disappeared before interacting with background elements:
   ```typescript
   await page.locator('.cdk-overlay-backdrop').waitFor({ state: 'detached', timeout: 5000 });
   ```
