# 📑 Полный справочник модулей, полей и сквозного флоу Creatio (Xlab Master Table)

Данный документ содержит полные структурированные таблицы по **всем бизнес-модулям**, **пошаговому заполнению полей на каждой странице** и **матрице 14 контрольных точек сквозного E2E тестирования**.

## 🧩 ТАБЛИЦА 1. Карта всех бизнес-модулей Creatio

| Иконка / Модуль | Раздел в Creatio | URL-маршрут (Shell) | Назначение модуля простыми словами |
| :--- | :--- | :--- | :--- |
| **🏭 Оборудование** | `Обладнання` | `#Section/GenEquipment_ListPage` | Реакторы для варки массы (в кг) и фасовочно-паковочные автоматы (в шт/час). |
| **🧪 Продукты** | `Продукти` | `#Section/Products_ListPage` | **3 типа:** 1. *Сырье* (вода, ПАВ, тара), 2. *Полуфабрикаты / НФ* (масса до розлива), 3. *Готовая продукция / ГП* (флакон). |
| **📜 Техкарты (ТК)** | `Технологічні карти` | `#Section/GenProductionRouting_ListPage` | Пошаговый рецепт и маршрут (этапы «Варка», «Фасовка», «Упаковка» и привязка к оборудованию). |
| **📦 Спецификации** | Вкладка `Матеріали` | Внутри карточки ТК | Состав: сколько грамм основы, крышек и флаконов расходуется на 1 готовую единицу. |
| **⏰ Рабочие смены** | `Зміни` | `#Section/GenWorkShift_ListPage` | График работы завода на целевую неделю (фонд доступных рабочих часов оборудования). |
| **📈 План ГП (ПГП)** | `План готової продукції` | `#Section/GenPlanFinishProduct_ListPage` | Месячный план продаж (сколько единиц ГП нужно произвести за месяц). |
| **🧮 Расчёт производства** | `Розрахунок виробництва` | `#Section/GenProductionCalculat_ListPage` | «Мозг» системы: автоматически раскладывает месячный план на 3 уровня (ГП ➔ НФ ➔ Сырье). |
| **📅 План производства** | `План виробництва` | `#Section/GenProductionPlan_ListPage` | Оперативный недельный план: расчет дефицита, запуск алгоритмов и утверждение. |
| **📋 Заказы цеха** | `Виробничі замовлення` | `#Section/GenProductionTask_ListPage` | Наряды на конкретную варку в реакторе или розлив с точным временем старта и финиша. |

## 🎯 ТАБЛИЦА 3. Матрица 14 контрольных точек сквозного E2E тестирования

| № | Фаза теста | Раздел / Компонент | Контрольное действие | Что валидируется в тесте |
| :-: | :--- | :--- | :--- | :--- |
| **1** | Фаза 1: Мастер-данные | `Обладнання` | Создание Реактора и Фасовочного автомата | Заполнение объема (1000 кг), калибровочных часов (50%, 75%, 95%) и производительности. |
| **2** | Фаза 1: Мастер-данные | `Продукти` | Создание Сырья, Полуфабриката (НФ) и ГП | Валидация категорий, единиц измерения и срока годности FEFO (730 дней). |
| **3** | Фаза 1: Мастер-данные | `Технологічні карти` | Создание ТК для НФ и ГП | Наличие этапов («Варка», «Фасовка», «Упаковка») и привязка к оборудованию. |
| **4** | Фаза 1: Мастер-данные | Вкладка `Матеріали` | Добавление спецификации сырья в ТК | Нормы расхода основы (кг), флаконов и компонентов (шт). |
| **5** | Фаза 2: Спрос | `Зміни` | Создание рабочих смен на плановую неделю | График `08:00 - 20:00`, привязка производственной линии. |
| **6** | Фаза 2: Спрос | `План готової продукції` | Создание плана на месяц (10 000 шт) + «Затвердити» | Перевод в статус `Затверджено` 🔒. |
| **7** | Фаза 2: Спрос | `Розрахунок виробництва` | Автогенерация 3-уровневого дерева декомпозиции | Проверка строк: ГП (10 000 шт), НФ (2 500 кг), Сырье (флаконы, вода, ПАВ). |
| **8** | Фаза 3: План недели | `План виробництва` | Создание плана на неделю (Пн-Вс) | Привязка активного Расчета производства и дат. |
| **9** | Фаза 3: План недели | Вкладка `Продукти плану` | Выбор продуктов с дефицитом | Чекбокс «Включити до плану». |
| **10** | Фаза 3: План недели | Кнопка «Запланувати» | Клик `✓ Запланувати виробництво` | Автоматическое создание строк Производственных заказов (ВЗ). |
| **11** | Фаза 4: Алгоритмы | Кнопка «Підібрати» | Клик `✓ Підібрати обладнання` | Автоподбор наименее загруженного реактора/линии и расчет времени. |
| **12** | Фаза 4: Алгоритмы | Модальное окно | Подтверждение загрузки > 80% (если возникло) | Автоматическое нажатие «Так / Продовжити». |
| **13** | Фаза 4: Алгоритмы | Шапка Плана | Клик `Затвердити` | Переход статуса Плана в **`Затверджено`** 🔒. |
| **14** | Фаза 4: Финал | `Виробничі завдання` | Валидация защиты и нарядов цеха | Проверка Read-Only блокировки полей и статуса `До виконання` у заказов. |

## 🛡️ ТАБЛИЦА 4. Правила стабильности UI (Антипаттерны vs Решения)

| ❌ Плохая практика (Флакует) | В чём опасность / Почему ломается | ✅ Как сделано у нас (Стабильно) |
| :--- | :--- | :--- |
| `page.waitForTimeout(5000)` | Слепая пауза. Если сервер ответил за 100мс — теряем время; если за 5100мс — тест падает. | `waitForCreatioReady()`: динамическое ожидание исчезновения `.crt-loading-mask` и `mat-spinner`. |
| `if (await isVisible()) { fill() }` | Если поле прогружалось на 50мс дольше, оно **тихо пропускается**, и тест падает позже. | Строгие Web-First ожидания `await locator.waitFor({ state: 'visible' })`. |
| Прямой клик по Combobox | При вводе Angular фильтрует список асинхронно ➔ клик по старому DOM (`stale element`). | `safeSelectCombobox`: дебаунс ввода + фильтрация опций + игнорирование кнопки «+ Додати новий». |
| Хардкод названий (`"Шампунь 1"`) | Конфликты при повторном запуске, дубли артикулов и зависимость от «грязной» базы. | Генерация уникального `Run ID` (`_E2E_${timestamp}`) для каждого прогона. |
| Хардкод URL (`https://xlab...`) | Тест падает при переключении между серверами `main` и `main2`. | Универсальный роутинг через `getShellUrl('#Section/...')`. |
